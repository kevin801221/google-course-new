# 各縣市避難收容處所欄位差異

正規化目標 schema：`{name, district, address, capacity, note}`。
實作在 `src/civicguard/shelters.py` 的 `ALIASES`——**新縣市只加別名字串，不要新開函式**。

| 目標欄位 | 已知別名 |
|---|---|
| `name` | 名稱／場所名稱／收容處所名稱／避難收容處所 |
| `district` | 分區（台南）／區域（高雄）／鄉鎮市區（宜蘭）／行政區 |
| `address` | 地址／位置／地址及備註（宜蘭） |
| `capacity` | 可容納人數／容量／收容人數 |

## 已知髒法

1. 宜蘭把地址與備註塞在同一欄，用「（備註：」分隔 → `normalize()` 會切開放進 `note`。
2. 人數欄位混雜「約 300 人」這種字串 → 只有純數字才轉 `int`，其餘保留原字串以利追溯。
3. 空欄位有時是 `null`、有時是空字串 → 別名比對時兩者都當「沒有」。
