# 特報分級規則

## 雨量分級（24 小時累積，毫米）

| 門檻 | 等級 |
|---|---|
| ≥ 350 | 超大豪雨 |
| ≥ 200 | 大豪雨 |
| ≥ 80 | 豪雨 |
| ≥ 40 | 大雨 |
| < 40 | 無 |

實作在 `src/civicguard/brief.py` 的 `RAIN_LEVELS`，由大到小比，第一個成立的就是答案。

## 不得四捨五入（D-008）

所有數值一律以**原始精度**輸出，分級判斷也用原始值。

理由：地震規模 5.45 被四捨五入成 5.5 之後跨過了簡報用語的分級門檻，文案就會誇大。
雨量 79.9 毫米同理，四捨五入後會從「大雨」跳到「豪雨」。

回歸測試：`uv run civicguard-brief --self-check` 會斷言 `rain_level(79.9) == "大雨"`
且文案裡出現 `79.9`、不出現 `80`。

## 用語約定

- 有特報：`{縣市}目前有{現象}特報，請提高警覺。`
- 無特報：`{縣市}目前無生效特報，維持正常作息。`
- 同一種現象出現多次只講一次（用 `dict.fromkeys` 去重保順序）。
